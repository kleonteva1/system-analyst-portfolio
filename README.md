# Портфолио системного аналитика - Кристина Леонтьева

Начинающий системный аналитик с образованием в области прикладной информатики. В портфолио собраны учебные проекты и практические работы по анализу и формализации требований, моделированию бизнес-процессов и данных, проектированию API и системных взаимодействий.

## Проекты

### 1. Система онлайн-бронирования переговорных комнат

**Задача:** спроектировать систему, позволяющую сотрудникам находить свободные переговорные комнаты по заданным параметрам, просматривать доступные временные интервалы, создавать, изменять и отменять бронирования.

**Что сделано:**

* собраны и формализованы требования к системе;
* описаны User Story, критерии приёмки и Use Case;
* смоделирован бизнес-процесс бронирования;
* спроектирована структура данных;
* смоделированы системные взаимодействия;
* разработан прототип пользовательского интерфейса;
* подготовлены SQL-скрипты для создания структуры и тестовых данных, а также операционные и аналитические запросы.

**Артефакты:** требования · User Story · Use Case · BPMN · ERD · Sequence Diagram · прототип · SQL

**Инструменты:** StormBPMN · Miro · PlantUML · SQL (синтаксис PostgreSQL)
